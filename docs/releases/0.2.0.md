# xmlsquish 0.2.0

- 发布日期 / Release date: 2026-09-11
- 标签 / Tag: `v0.2.0`
- 最低 Rust 版本（Minimum Supported Rust Version, MSRV）: **1.88**

0.2.0 实现新的 XML 宏语言，并统一为单二进制架构。这是一次破坏性语言更新，不提供 0.1 语法或 Rust 库接口兼容层。规范以 [DSL 文档](https://xmlsquish.moesegfault.dev/ns/0.2.0/dsl.md) 为准。

0.2.0 implements the new XML macro language and consolidates the project into a single binary. This is a breaking language release with no compatibility layer for 0.1 syntax or the former Rust library interface. The [DSL specification](https://xmlsquish.moesegfault.dev/ns/0.2.0/dsl.md) is normative.

## 安装 / Installation

## 语言与迁移 / Language and migration

| 0.2.0 契约 / Contract | 迁移操作 / Migration |
| --- | --- |
| 内建操作按 URI 识别 / Builtins use namespace identity | 将源码包在 `xs:module` 中并绑定下方 URI / Wrap sources in `xs:module` and bind the URI below |
| 宏使用命名空间限定名（QName） / Macros use namespace-qualified names | 用 `xs:macro name="app:name"` 和 `xs:call ref="app:name"` 明确声明与调用 / Declare and call names explicitly |
| 参数不继承 / No inherited arguments | 用 `xs:param` 声明、`xs:arg` 传入；入口用 `--arg NAME=VALUE` / Declare and pass arguments; supply entry values with `--arg` |
| XML 插槽显式传递 / Explicit XML slots | 用 `xs:fill` 向 `xs:slot` 传递节点，而不是隐式上下文 / Pass nodes with fills rather than implicit context |
| 普通文本无 `$` 插值 / No `$` text interpolation | 用 `xs:insert get="arg.name"` 读取标量 / Read scalars using `xs:insert` |
| 单二进制 / Single binary | 通过 CLI 使用；编译器模块不是公共 Rust 库 / Use the CLI; the compiler is not a public Rust library |

```xml
<xs:module xmlns:xs="https://xmlsquish.moesegfault.dev/ns">
  <xs:param name="name"/>
  <Greeting>Hello, <xs:insert get="arg.name"/>!</Greeting>
</xs:module>
```

保存为 `hello.xml` 后运行 / Save as `hello.xml`, then run:

```bash
xmlsquish --arg name=Klee hello.xml
```

命名空间标识与参考页 / Namespace identity and reference: [https://xmlsquish.moesegfault.dev/ns](https://xmlsquish.moesegfault.dev/ns).

## 执行与输出 / Execution and output

- 完整静态源码闭包在执行前验证；未选中的分支也检查引用和模式。导入只装载定义；`mount` 执行目标模块主体。纯导入环合法，实际递归受预算约束。
  Validate the entire static source closure before execution, including references and patterns in unselected branches. Imports load definitions; mounts execute module bodies. Import cycles are legal; execution recursion is budgeted.
- `-I` 输出含来源信息（provenance）的 `.i.xml`；默认 `-O` 输出 `.o.xml`。诊断包含相关源码位置和展开调用链。
  `-I` emits provenance-bearing `.i.xml`; default `-O` emits `.o.xml`. Diagnostics include relevant source locations and expansion calls.
- **最终 `.o.xml` 继续压缩空白，空白作为无意义的格式内容处理；这是既有产品语义，未在本次版本中改变。** 宏展开与去除内部信息阶段保留文本，不意味着最终产品承诺保留 XML 混合内容的空白。
  **Final `.o.xml` continues to squish whitespace as insignificant formatting; this established product behavior is unchanged.** Text preservation during expansion and internal-information removal is not a promise of mixed-content whitespace fidelity in the final product.
- 不覆盖输入源码；失败的展开不提交部分输出。独立输入可继续处理，但任一失败使命令返回非零退出码。
  Sources are not overwritten and failed expansion does not commit partial output. Independent inputs may continue, but any failure causes a nonzero exit status.

## 资源与安全边界 / Resource and security boundaries

| 选项 / Option | 默认值 / Default | 范围 / Scope |
| --- | --- | --- |
| `--max-depth` | `1024` | 同时活动的宏展开帧 / Simultaneously active macro frames |
| `--max-expansions` | `100000` | 宏帧创建总数 / Total macro frame creations |
| `--max-output-bytes` | `67108864`（64 MiB） | 最终输出与每个临时 argument/fill 序列的序列化字节数 / Serialized bytes of final output and each temporary argument/fill sequence |

字节预算分别检查缓冲区，**不是所有活动分配之和，不包含全部来源中间表示（Intermediate Representation, IR）开销，也不是进程总内存限制**。默认加载器仅支持可表示为本机路径的 `file:` URI，拒绝其他协议、query 与 fragment；路径规范化不解引用符号链接。它不是文件访问沙箱。处理不可信源码需要外部文件权限与进程资源隔离。

The byte guard checks buffers separately: **it is not an aggregate allocation limit, does not include all provenance-IR overhead, and is not a process-memory limit**. The default loader supports only `file:` URIs representable as native paths, rejecting other schemes, queries, and fragments; path normalization does not dereference symlinks. It is not a filesystem sandbox. Untrusted sources require external filesystem controls and process-resource isolation.
