## Agent Skills 成为工作区依赖 / Agent Skills as workspace dependencies

1.1.0 将 Agent Skills 纳入 Cargo 风格的显式依赖生命周期，但**不**把它们伪装为 XML 包。工作区根 `xmlsquish.toml` 的 `[skills]` 声明本地目录或 Git 来源；`xmlsquish.lock` 的独立 `[[skill]]` 记录固定来源、Git 精确提交及整棵技能目录的 BLAKE3 摘要；面向 Agent 的安装副本位于工作区根 `.agents/skills/<name>/`。现有无技能项目无需迁移清单或锁文件。

Version 1.1.0 manages Agent Skills with an explicit, Cargo-like dependency lifecycle, **separate** from XML packages. The workspace-root `[skills]` table declares a local directory or Git source. Independent `[[skill]]` lock entries pin source identity, exact Git commit, and a BLAKE3 digest of the entire skill tree. Agent-visible copies live under the workspace root's `.agents/skills/<name>/`. Existing projects without skills need no manifest or lock migration.

```toml
[skills]
review-checks = { path = "tools/skills/review-checks" }
release-notes = { git = "https://example.com/agent-skills.git", tag = "v2", subdir = "release-notes" }
```

| 命令 / Command | 作用 / Purpose |
| --- | --- |
| `xmlsquish add-skill NAME --path DIR` | 安装包含 `SKILL.md` 的确切本地目录，并协调声明、锁和副本 / Declare, lock, and install one local skill directory. |
| `xmlsquish add-skill NAME --git URL [--rev OID\|--tag TAG\|--branch BRANCH] [--subdir DIR]` | 安装仓库根或指定子目录的一个技能，锁定精确提交 / Install one Git skill and pin the exact commit. |
| `xmlsquish remove-skill NAME` | 删除声明、锁记录及未被改动的受管副本 / Remove declaration, pin, and unchanged managed copy. |
| `xmlsquish sync-skills --locked` | 检出后按锁文件恢复并协调副本 / Reconcile the projection after checkout. |
| `xmlsquish install-skill [--project]` | 安装可执行文件内嵌的 xmlsquish 自带指南 / Install the executable-bundled xmlsquish guide. |

`add-skill` 必须明确指定 `--path` 或 `--git`；**没有**裸名称默认技能仓库，也不复用 XML 包 registry。`--path` 是直接包含 `SKILL.md` 的目录，声明路径相对于工作区根清单。Git 未指定 revision/tag/branch 时以远端 HEAD 为可变选择器，但锁中仍固定解析到的提交。技能名必须与 `SKILL.md` frontmatter 的 `name` 和目标目录一致，frontmatter 还需有效的 `description`。所有项目技能命令作用于工作区根；从成员包或通过 `--manifest-path` 指向成员调用也是如此。

`add-skill` requires an explicit `--path` or `--git`: there is **no** bare-name skill registry, and the XML package registry is not reused. A local path identifies the directory directly containing `SKILL.md` and is recorded relative to the workspace-root manifest. An omitted Git selector follows remote HEAD while the lock still pins its resolved commit. The name must agree with the `SKILL.md` frontmatter and destination directory; a valid description is required. Skill operations always target the workspace root, including calls made from a member package.

### 自带指南 / Bundled guide

`install-skill` 安装随二进制内嵌的 `prompt-squish` 指南，**不修改**项目清单或锁文件。默认位置是 Unix 的 `$HOME/.agents/skills/prompt-squish` 或 Windows 的 `%USERPROFILE%\.agents\skills\prompt-squish`；`--project` 改为当前工作区的 `.agents/skills/prompt-squish`。用户也可从本次 Release 下载独立的 `SKILL.md` 资产；它与六个平台归档一同列入 `SHA256SUMS`。独立资产便于人工审阅；CLI 自安装无需另外下载文件。

`install-skill` installs the binary-embedded `prompt-squish` guide **without modifying** the project manifest or lock. By default it goes to `$HOME/.agents/skills/prompt-squish` on Unix or `%USERPROFILE%\.agents\skills\prompt-squish` on Windows; `--project` selects the current workspace. The guide is also available as a standalone `SKILL.md` Release asset, included with all six archives in `SHA256SUMS` for review or manual use. CLI self-install does not require a separate download.

### 锁定、恢复与安全边界 / Locking, recovery, and safety

`--locked` 禁止改写锁，`--offline` 禁止网络访问，`--frozen` 合并两者；`--dry-run` 验证并报告计划但不提交。检出后可执行 `sync-skills --locked`，离线环境需要事先具备所需的精确 Git 对象。**本地路径依然可变**：若来源内容变化，请显式重新执行 `add-skill` 更新锁；锁定同步会拒绝漂移，不会把旧摘要当作新内容的授权。

`--locked` forbids lock edits, `--offline` forbids network, `--frozen` combines both, and `--dry-run` validates without committing. Run `sync-skills --locked` after checkout; offline use requires the exact Git objects to be available locally. **Local paths remain mutable**: intentionally refresh them with `add-skill`; locked sync refuses source drift instead of blessing new bytes under an old digest.

安装使用普通目录副本而非指向来源的符号链接。清单、锁与安装视图由可恢复事务协调。工具不会覆盖、接管或删除手工安装的目录，也不会覆盖或删除用户改动过的受管目录。重复安装相同的自带指南是幂等的；`install-skill --force` 仅能替换未经编辑的、自身所有的旧安装。下载或安装不执行技能中的脚本。摘要只证明文件一致性，**不证明第三方技能安全**；启用前应审阅来源与指令。

Installations are ordinary directory copies, not symlinks to mutable sources. A recoverable transaction coordinates the manifest, lock, and projection. The tool neither adopts/removes manual directories nor overwrites/removes user-edited managed trees. Bundled installation is idempotent; `install-skill --force` can only replace an unchanged, self-owned prior installation. Acquisition does not execute skill scripts. A digest establishes byte identity, **not third-party skill safety**; review source and instructions before enabling them.

## 自动化兼容性 / Automation compatibility

机器协议从 `3.1` **可加性**升级至 `3.2`：新增有类型的技能请求、事件、结果；现有构建、XML 包依赖、`inspect`、XML DSL 命名空间及退出码语义不变。读取 `--message-format=json` 的程序应将技能操作视为独立类型，而非 XML 包依赖。旧的无技能 manifest-v1 与 lock-v1 仍可读取；新增 `[[skill]]` 的项目不应期待旧版本 CLI 能管理它们。Rust 最低支持版本仍为 1.88。仓库不发布到 crates.io。

The machine protocol advances **additively** from `3.1` to `3.2` with typed skill requests, events, and results. Existing build, XML-package, inspection, XML DSL namespace, and exit semantics are unchanged. JSON consumers should treat skill operations as distinct types. Old skill-free manifest-v1 and lock-v1 files remain readable; projects containing new `[[skill]]` records should not expect older CLIs to manage them. Minimum supported Rust remains 1.88. This project is not published to crates.io.

## 安装 / Install

从 [v1.1.0 GitHub Release](https://github.com/kleedaisuki/prompt-squish/releases/tag/v1.1.0) 下载平台归档及同次发布的 `SHA256SUMS`，核对准确文件名的 SHA-256 后解压，把可执行文件加入 `PATH`。Linux 二进制依赖 glibc ≥ 2.35，**不是** Alpine/musl 构建。macOS 最低 11.0。当前二进制未做代码签名或 Apple 公证；校验和单独证明下载字节完整性，不证明发布者身份。

Download the platform archive and `SHA256SUMS` from the [v1.1.0 GitHub Release](https://github.com/kleedaisuki/prompt-squish/releases/tag/v1.1.0). Verify the SHA-256 row for the exact filename before extracting and adding the binary to `PATH`. Linux requires glibc ≥ 2.35 and is **not** an Alpine/musl build; macOS requires 11.0+. The binaries are unsigned and not Apple-notarized. A checksum alone verifies bytes, not publisher identity.

| 系统 / OS | 架构 / Architecture | 资产 / Asset |
| --- | --- | --- |
| Windows 10 / 11 | x86-64 | `xmlsquish-1.1.0-x86_64-pc-windows-msvc.zip` |
| Windows 10 / 11 | ARM64 | `xmlsquish-1.1.0-aarch64-pc-windows-msvc.zip` |
| Linux · glibc ≥ 2.35 | x86-64 | `xmlsquish-1.1.0-x86_64-unknown-linux-gnu.tar.gz` |
| Linux · glibc ≥ 2.35 | ARM64 | `xmlsquish-1.1.0-aarch64-unknown-linux-gnu.tar.gz` |
| macOS ≥ 11 | Intel | `xmlsquish-1.1.0-x86_64-apple-darwin.tar.gz` |
| macOS ≥ 11 | Apple Silicon | `xmlsquish-1.1.0-aarch64-apple-darwin.tar.gz` |

从不可变标签源码安装 / Install from the immutable source tag:

```console
cargo install --git https://github.com/kleedaisuki/prompt-squish --tag v1.1.0 --locked
xmlsquish --version
xmlsquish install-skill --dry-run
```

GitHub Actions 在 Rust 1.88 的 Linux、Windows、macOS 上运行完整 workspace 测试及 CLI 冒烟测试；发布前还检验标签、版本、锁文件、更新日志与本页一致。六个平台归档从同一不可变标签原生构建，只有全部成功后才由聚合作业发布 Release 与 `SHA256SUMS`。

GitHub Actions runs the complete workspace tests and CLI smoke checks on Linux, Windows, and macOS with Rust 1.88. Before publication it verifies agreement among tag, version, lockfile, changelog, and this page. Six native platform archives are built from the same immutable tag; only the successful full matrix permits the aggregation job to publish the Release and `SHA256SUMS`.
