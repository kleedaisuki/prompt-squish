### Required fixture repairs discovered

1. `squish-link/src/tests.rs::borrowed_static_scalar_matches_task_evaluation_with_exact_budget_errors`: appending an empty string to the fixture's `["X", "ab"]` semantic pool creates `["X", "ab", ""]`. Public `reconstruct_shared` reaches `MiddleEnd::optimize_shared` and `validate_header`, which rejects this unsorted pool before the oracle can execute. The test's `unwrap` panics. Preserve sorted strings and remap IDs coherently, or use a valid empty-string fixture; do not weaken validation. Confidence: high, direct deterministic contract violation. Reported to `/root/compiler` and `/root/review`.

2. `squish-ir/src/persistent.rs::borrowed_projections_preserve_all_four_kinds_and_large_literal_bytes`: the original module fixture has macro body RegionId(0). Constructing SOPack with the same root RegionId(0) produces two root owners, rejected by `validate_arena`'s exactly-one-owner invariant. Append a separate empty SOPack root. Confidence: high. Reported to `/root/ir_codec` and `/root/review`.

3. `squish-link/src/middle.rs::optimize_validated`: the crate-private owned wrapper had no production caller, only a test caller. Check `dead_code` under the hosted quality job's `-D warnings`; deleting the unused wrapper or limiting it to tests avoids carrying an unnecessary production entry point. Reported to `/root/compiler`. This is a source-inferred build risk, not an executed compiler result.

## Preserved contracts observed

- Entry arguments still append all initial scalar values in BTreeMap name order, including duplicates. HashMap `entry(...).or_insert` retains the first corresponding arena ID, matching the old `.position` oracle. Runtime interning only appends on misses; HashMap iteration never drives serialized order. Final scalar canonicalization sorts indices by exact text, moves text, deduplicates, and remaps every frame and ExternalArgument ID explicitly, including empty strings.
- Borrowed operation/argument/fill/definition lifetimes come from the external immutable program, not mutable Machine storage. Task scheduling, value ownership when needed by output/environment, origin resolution and budget checks remain in place. Static scalar segments are borrowed, but each emitted occurrence still owns its necessary text and retains the original operation provenance; static match capture ranges are borrowed through Cow without merging capture scopes.
- `LinkedProgram` clones share private immutable ProgramData through Arc. Shared closures share exact payloads, not namespace binding state; each entry independently constructs symbols and relocations. Public middle/link/reconstruction boundaries still validate untrusted inputs before direct indexing; only crate-private already-validated paths skip repeated scans.
- Fresh linking validates all snapshot payloads, including unreachable ones, before optimizing reachable units. Eager regex compilation and bounded static scalar facts are unchanged mechanisms; this review does not imply global fact reuse across independently linked include scopes.
- Public reconstruction now checks exact root/signature, schema/language ABI, definition coverage/body/signature/symbol, symbol map, feature aggregation and complete call relocation correspondence. Fresh internal reconstruction receives an image generated from validated units and structurally checked by the private ValidatedImage constructor. The formerly documented arbitrary arena mismatch is no longer admitted by the public reconstruction path.
- Container decode validates directory/order/flags/offsets/digests/exact EOF before exposing borrowed payload slices. The typed decoder still decodes/validates complete debug IR and checks descriptor/kind plus exact canonical semantic projection, without allocating a second projection. Public owned decode remains an owned copy wrapper.
- DomainHasher retains `xmlsquish\0`, domain bytes, zero separator and payload order. Partition digests preserve major/kind and each selected section's tag/length/payload. Object digest streams the same header/directory followed by payloads. Direct unit writer retains v1 header, sorted three sections, flags, offsets, lengths and section digest order; semantic projection strips exactly origins/archive/source digest/source-record/producer fields stripped by HEAD.
- Borrowed relocation overrides retain import arena IDs and expected kinds, validate new source/import metadata, map source records/attachments consistently, and leave immutable input arenas unchanged. An explicit source override must agree with source-key mapping; standalone inconsistent override is rejected rather than emitting invalid attachment identity.

## Deliberate limits and pending evidence

The reconstruction API still trusts caller-supplied ObjectDigest and image semantic-digest labels; the new correspondence check is structural/binding correspondence, not cryptographic recomputation of those labels from every supplied payload. This is a preexisting caller-authentication responsibility, not a newly demonstrated legitimate-CLI failure. Do not claim all possible cross-object identities are cryptographically proven by reconstruction alone. Regex ABI comparison among cached reconstruction units is also not newly established by this patch.

Legacy writer comparison, four-kind/large-literal coverage, relocated-vs-owned metadata comparison, semantic tamper rejection, duplicate entry scalar IDs, shared pointer identity, forged image rejection and static-vs-task budget equality have been read as authored tests. They are not executed evidence. Hosted compilation/Clippy, native regression results and paired canonical output/allocation/time results remain required. The codec test oracle retains the former owned strip operation but uses the shared primitive wire writer; it strongly checks projection/container equivalence, not independent correctness of every unchanged primitive field encoding.
