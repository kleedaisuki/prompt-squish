inserted. This removes the pre-serialization identity projection work of

M12 new tied-seed fast path: `anchored_order` selects the lexicographically least
UNIQUE seed in a tied SCC, then performs BFS over sorted unique-labelled edges.
Labels include length-delimited importer logical path, import slot and target
logical path; complete binding validation gives unique importer slots. Neither
input vector indices nor physical host paths break ties. Strong connectivity
guarantees coverage from the anchor. The shared G-sized visit-mark array is
allocated ONCE outside the component loop, and component stamps avoid G-sized
clearing for every SCC. The 512-provider equal-seed ring with one distinguished
root now requires one canonical walk, not G refinement rounds; authored reversal

residual is recorded rather than hidden behind a global O(G+E) claim. Existing
old-reader namespace acceptance still concerns opaque schema-1 relocated paths,
