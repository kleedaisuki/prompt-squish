# Borrowed backend emission

Date: 2026-10-01. Scope: `squish-backend` request and pure emitter boundary.

The owned `BackendRequest` API remains supported. Additive `BackendRequestRef` and
`Backend::emit_ref` let pipeline consumers retain immutable document/trace state without
cloning it into a staging request. The trait default constructs the old owned request,
so existing custom backend implementations remain source compatible.

`SquishBackend` overrides the borrowed operation. Its common emission helper borrows the
document, validates both inputs, checks trace alignment, negotiates the document dialect,
and validates XML before taking ownership of output provenance. Owned requests transfer
trace ownership; borrowed requests copy the trace once, necessarily, because
`BackendOutput` owns a trace extended by backend transform/synthetic nodes. No document
copy is performed by the production borrowed backend. The full outgoing trace and byte
map validators remain in place; borrowing does not make externally supplied IR trusted.

Parity tests compare complete output values (bytes, map, trace, metrics and cache identity),
assert input immutability, compare malformed/dialect/alignment/XML/budget errors, and
exercise an existing owned-only backend through the default bridge. Verification performed
locally is formatting only; compile, test and allocation measurements belong to hosted CI.
